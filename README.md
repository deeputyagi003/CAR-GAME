# 🏎️ Car Racing Game

A fun and interactive Car Racing Game built using **HTML, CSS, and JavaScript**.

The player controls a car, avoids obstacles, and tries to achieve the highest possible score.

## ✨ Features

- 🚗 Smooth car movement
- 🛣️ Racing road interface
- 🚧 Obstacle avoidance
- 🎯 Score tracking
- 💥 Collision detection
- 🔄 Restart / Reset game
- 📱 Responsive design
- 🎨 Modern and interactive UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🎮 How to Play

1. Start the game.
2. Use the keyboard controls to move the car.
3. Avoid incoming obstacles.
4. Keep driving to increase your score.
5. If the car hits an obstacle, the game ends.
6. Click the **Restart** button to play again.
